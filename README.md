# 🌊 Checkpoint 04 — Grid Layout

Projeto desenvolvido para o **Checkpoint 04** do curso de **Engenharia de Software**, com o objetivo de aplicar conceitos de **HTML5 e CSS3**, principalmente o uso de **CSS Grid Layout** na construção de uma página web responsiva.

[🌐 Acessar o projeto](https://leonardo-daniel-sc.github.io/CP4-Front-End/)

## 📌 Sobre o projeto

A página possui diferentes seções organizadas através de layouts em Grid, incluindo uma área principal com imagens, uma galeria, depoimentos de clientes e um rodapé com informações de contato e redes sociais.

## 🚀 Funcionalidades

* 🏠 Seção inicial com destaque visual
* 🖼️ Galeria de imagens
* 💬 Seção de avaliações dos clientes
* 📱 Estrutura preparada dispositivos móveis
* 🧭 Menu de navegação entre as seções
* 📞 Área de contato
* 📱 Links para redes sociais
* 📐 Utilização de **CSS Grid Layout**

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **CSS Grid**
* **Flexbox**
* **Git e GitHub**

## 🎨 Seções da página

### 🏠 Início

A seção principal apresenta imagens de destaque e um texto introdutório, acompanhados por um botão de acesso.

### 🖼️ Galeria

A galeria apresenta diferentes imagens organizadas em um layout visual utilizando CSS Grid.

### 💬 Depoimentos

A seção de avaliações apresenta três cards contendo imagens de perfil e comentários de clientes.

### 📞 Contatos

O rodapé reúne:

* Informações sobre o projeto
* Links de navegação
* E-mail
* Telefone
* Localização
* Redes sociais
* Informações de direitos autorais

## 📚 Objetivo acadêmico

O principal objetivo deste projeto é colocar em prática os conhecimentos adquiridos sobre **CSS Grid Layout**, trabalhando com organização de elementos, posicionamento, espaçamento e estruturação de diferentes áreas de uma página web.
